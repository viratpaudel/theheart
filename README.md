# 💖 The Heart

A beautiful animated heart drawn with Python's `turtle` graphics, featuring the word **"love"** written in **50 different languages** around the outline.

## How to Run

```bash
python heart.py
```

## Requirements

- Python 3.x
- `turtle` (included in the standard library)
- `tkinter` (included in most Python distributions)

## What It Does

- Renders a parametric heart curve using the classic heart equation
- Places "love" in 50 languages along the heart outline
- Each word pops in with a smooth easing animation
- Pink text on a black background
