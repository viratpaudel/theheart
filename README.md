# 💖 The Heart

An animated Python Turtle graphics visualizer that renders a heart shape constructed entirely from the word **"Love"** rendered in 50 different languages.

---

## ✨ Features

- **Mathematical Heart Curve**: Calculates heart contour coordinates using parametric parametric equations.
- **50 Languages**: Displays the word "Love" across diverse languages and scripts (e.g., Arabic, Hindi, Mandarin, Japanese, Spanish, French, Swahili, etc.).
- **Dynamic Text Scaling**: Automatically measures and sizes font bounds with Tkinter font metrics to wrap words around the heart outline.
- **Pop-in Animation**: Features dynamic animated transitions as each word lands on the heart boundary.

---

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Tkinter / Turtle (included in standard Python on most installations)

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/viratpaudel/theheart.git
   cd theheart
   ```

2. Run the script:
   ```bash
   python heart.py
   ```
